# План автоматизации тестирования

## 1. Перечень автоматизируемых сценариев

### 1.1. Валидные данные (используются во всех позитивных сценариях)

| Поле | Общее описание | Конкретный пример |
|------|----------------|-------------------|
| Номер карты | 16 цифр, карта из `data.json` | `4444 4444 4444 4441` (APPROVED) |
| Месяц | Двузначное число от 01 до 12 | `12` |
| Год | Две последние цифры года, не меньше текущего | `27` (текущий +1) |
| CVC | Три цифры | `123` |
| Владелец | Латиница, имя и фамилия через пробел | `IVAN IVANOV` |

### 1.2. Покупка тура по дебетовой карте (Payment Gate, `/payment`)

#### Позитивные сценарии

**Сценарий №1: Успешная оплата тура APPROVED-картой (оплата)**

- **Шаги:**
  1. Открыть главную страницу `http://localhost:8080`
  2. Нажать кнопку «Купить»
  3. Заполнить форму валидными данными
  4. Нажать «Продолжить»
  5. Проверить запись в БД (`payment_entity`)
- **Данные:** карта `4444 4444 4444 4441`, месяц `12`, год `27`, CVC `123`, владелец `IVAN IVANOV`
- **Ожидаемый результат:** Появляется сообщение об успешной операции, в таблице `payment_entity` запись со статусом `APPROVED`

#### Негативные сценарии

Все сценарии валидации полей являются негативными. При вводе невалидных данных операция приобретения тура **не может быть выполнена успешно**.
