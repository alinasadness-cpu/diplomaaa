# Отчёт об итогах автоматизации

## Что было запланировано

1. Настроить окружение: MySQL, PostgreSQL, gate-simulator (Docker).
2. Написать UI-автотесты для оплаты тура дебетовой картой (Payment Gate).
3. Написать UI-автотесты для покупки тура в кредит (Credit Gate).
4. Написать тесты валидации полей формы оплаты.
5. Добавить проверки записей в БД через `DbUtils`.
6. Настроить отчёты (Gradle, Allure).
7. Оформить документацию: `Plan.md`, `Report.md`, `Summary.md`, `README.md`.
8. Создать Issues по найденным багам.

## Что реализовано

| Пункт | Статус |
|-------|--------|
| Окружение MySQL + gate-simulator (Docker) |  Готово |
| Окружение PostgreSQL |  Не проверялось |
| Page Objects (`MainPage`, `PaymentPage`, `CreditPage`) |  Готово |
| UI-тесты оплаты дебетовой картой |  2 теста |
| UI-тесты покупки в кредит |  2 теста |
| UI-тесты валидации полей (оплата) |  14 тестов |
| Проверки записей в БД через `DbUtils` |  Готово |
| Отчёты Gradle HTML |  Работают |
| Отчёты Allure |  Не настроены |
| Документация (`Plan.md`, `Report.md`, `Summary.md`, `README.md`) |  Готово |
| Issues по найденным багам |  4 активных (#1, #2, #5, #6) |

**Итого:** 18 автотестов, 11 успешных, 7 падают из-за реальных багов SUT.

## Причины, по которым что-то не реализовано

1. **API-тесты** (REST Assured) — не реализованы, приоритет отдан UI-тестам.
2. **PostgreSQL** — не проверялся, прогон сделан только на MySQL.
3. **Allure** — не настроен, используется Gradle HTML-отчёт.

## Сработавшие риски

1. **Смена IP сервера** в середине работы (`185.119.56.254` → `94.228.123.24`).
2. **SUT хардкодил `localhost` в `application.properties`** — потребовалось заменить на IP сервера.
3. **Проблема с кодировкой** — селекторы переписаны без кириллицы.
4. **Порт 8080 занят** при перезапуске SUT.
5. **`ddl-auto=create-drop`** — таблицы удаляются при остановке SUT.
6. **Нестабильность SUT** — ошибки под полями появляются непоследовательно.
